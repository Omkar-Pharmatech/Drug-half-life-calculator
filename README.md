# Drug Half-Life Calculator

## What is this?
A small Python program that calculates how much of a drug
is left in the body after a certain time.

## Why did I make it?
I work/study in pharma. Half-life is an important idea in
pharmacokinetics, and I wanted to practice coding with it.

## The formula
Remaining amount = Starting dose × (0.5) ^ (time ÷ half-life)

## How to use
Run the file half_life.py and enter:
- the dose in mg
- the drug's half-life in hours
- the time passed in hours
